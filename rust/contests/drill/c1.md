# C-1: ペアの差を最小に

配点: 300点

### 問題文

$N$ 人（$N$ は偶数）がいて、人 $i$ は整数 $A_i$ を持っている。  
$N$ 人をちょうど $\dfrac{N}{2}$ 組のペアに分ける。ペアのコストは「2 人の持つ整数の差の絶対値」である。  
すべてのペアのコストの合計を**最小化**したとき、その合計値を出力せよ。

### 制約

- $2 \le N \le 2 \times 10^5$（$N$ は偶数）
- $1 \le A_i \le 10^9$
- 入力は全て整数

### 入力

```
N
A_1 A_2 ... A_N
```

### 出力

コスト合計の最小値を出力せよ。

---

### 入力例1

```
4
1 3 2 4
```

### 出力例1

```
2
```

ソートすると `[1,2,3,4]`。`(1,2)` と `(3,4)` のペアにすると $1+1=2$。これが最小。

---

### 入力例2

```
2
5 5
```

### 出力例2

```
0
```

---

### 入力例3

```
6
8 1 4 7 2 5
```

### 出力例3

```
3
```

ソートすると `[1,2,4,5,7,8]`。`(1,2)(4,5)(7,8)` で $1+1+1=3$。

---

### 練習ポイント（貪欲：ソートして隣どうし）

「ペアに分けて差の合計を最小化」と言われたら、**まずソート**して**隣り合う要素どうし**をペアにするのが最適。
離れた値どうしを組むと差が大きくなって損をする、という直感が交換論法（入れ替えても良くならない）の根拠。

認識トリガー: **「差・距離の合計を最小化」+「自由に組み合わせられる」→ ソートして隣接**。

実装は `sort()` してから `(0..n).step_by(2)` で `a[i+1]-a[i]` を足すだけ。
合計は最大 $10^5 \times 10^9 = 10^{14}$ になりうるので **`i64`**（オーバーフロー注意）。
