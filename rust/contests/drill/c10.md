# C-10: 迷路の最短手数

配点: 300点

### 問題文

$H \times W$ のグリッドがある。各マスは `.`（通行可能）、`#`（壁）、`S`（スタート）、`G`（ゴール）のいずれか。  
`S` から `G` まで、上下左右に隣接する通行可能マスへ 1 手で移動するとき、**最短の手数**を出力せよ。たどり着けない場合は `-1` を出力せよ。  
`S` と `G` はそれぞれちょうど 1 つ存在する。

### 制約

- $1 \le H, W \le 1000$
- 各マスは `.` `#` `S` `G` のいずれか
- 入力は全て上記の文字

### 入力

```
H W
（H 行のグリッド）
```

### 出力

最短手数、または `-1` を出力せよ。

---

### 入力例1

```
3 3
S..
.#.
..G
```

### 出力例1

```
4
```

右→右→下→下 などで 4 手。

---

### 入力例2

```
2 2
S#
#G
```

### 出力例2

```
-1
```

壁に囲まれて到達不能。

---

### 入力例3

```
1 2
SG
```

### 出力例3

```
1
```

---

### 練習ポイント（BFS：グリッド最短路）

「**辺の重みがすべて 1 の最短路**」は BFS。`VecDeque` のキューと、各マスの距離を持つ 2 次元配列 `dist`（未訪問は `-1`）を使う。

```rust
use std::collections::VecDeque;
let mut dist = vec![vec![-1i64; w]; h];
let mut q = VecDeque::new();
dist[si][sj] = 0;
q.push_back((si, sj));
let dir = [(0i64,1i64),(0,-1),(1,0),(-1,0)];
while let Some((i, j)) = q.pop_front() {
    for &(di, dj) in &dir {
        let ni = i as i64 + di;
        let nj = j as i64 + dj;
        if ni < 0 || nj < 0 || ni >= h as i64 || nj >= w as i64 { continue; }
        let (ni, nj) = (ni as usize, nj as usize);
        if grid[ni][nj] == '#' || dist[ni][nj] != -1 { continue; }
        dist[ni][nj] = dist[i][j] + 1;
        q.push_back((ni, nj));
    }
}
```

ポイント:
- グリッドは `Vec<Vec<char>>` か `Vec<Vec<u8>>` で受ける（`s.chars().collect()`）。
- **範囲外チェック**で `usize` のまま `-1` すると panic（アンダーフロー）。一度 `i64` にして判定してから `usize` に戻すのが安全。
- **訪問済み判定（`dist != -1`）を必ず**。これが無いと同じマスを何度も入れて TLE/無限ループ。

認識トリガー: **「グリッド／グラフ」+「最短手数・最短距離（重み 1）」→ BFS**。
$S, G$ の座標を最初に走査して見つけておくこと。
