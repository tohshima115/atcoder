# C-11: 連結成分の個数

配点: 300点

### 問題文

$N$ 頂点 $M$ 辺の無向グラフが与えられる。頂点には $1$ から $N$ の番号が付いている。  
このグラフの**連結成分の個数**（どの頂点からも辿れるグループがいくつあるか）を出力せよ。

### 制約

- $1 \le N \le 2 \times 10^5$
- $0 \le M \le 2 \times 10^5$
- $1 \le u_i, v_i \le N$
- 多重辺・自己ループは無いものとする
- 入力は全て整数

### 入力

```
N M
u_1 v_1
u_2 v_2
...
u_M v_M
```

### 出力

連結成分の個数を出力せよ。

---

### 入力例1

```
5 3
1 2
2 3
4 5
```

### 出力例1

```
2
```

`{1,2,3}` と `{4,5}` の 2 グループ。

---

### 入力例2

```
3 0
```

### 出力例2

```
3
```

辺が無いので各頂点が単独。

---

### 入力例3

```
4 4
1 2
2 3
3 4
4 1
```

### 出力例3

```
1
```

全頂点がつながって 1 グループ。

---

### 練習ポイント（BFS/DFS：連結成分の数え方）

隣接リストを作り、**まだ訪問していない頂点から BFS/DFS を 1 回始めるたびにカウントを 1 増やす**。1 回の探索でそのグループ全体を訪問済みにする。

```rust
let mut adj = vec![vec![]; n + 1];
for &(u, v) in &edges { adj[u].push(v); adj[v].push(u); }  // 無向は両方向
let mut seen = vec![false; n + 1];
let mut comp = 0;
for s in 1..=n {
    if seen[s] { continue; }
    comp += 1;
    // ここから s を起点に BFS（VecDeque）か DFS で連結成分を全部 seen にする
}
println!("{}", comp);
```

ポイント:
- **無向グラフは辺を両方向 push** する。
- 隣接リストは `vec![vec![]; n+1]` で 1-indexed のまま持つと楽。
- 探索の入口で `seen[v]` をチェック・セットして、二重訪問を防ぐ（再帰 DFS は深さ $2\times10^5$ でスタックオーバーフローの危険があるので、慣れないうちは **BFS（VecDeque）**推奨）。

認識トリガー: **「グループ分け」「つながっている頂点のかたまりの数」→ 連結成分（BFS/DFS、または Union-Find）**。
同じ型で「最大グループのサイズ」「各グループのサイズ」なども問われる。
