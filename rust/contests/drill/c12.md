# C-12: 区間加算の最大値（いもす法）

配点: 300点

### 問題文

数直線上の整数座標 $1, 2, \ldots, N$ がある。最初すべての座標の値は $0$。  
$M$ 個の操作があり、$i$ 番目の操作では区間 $[L_i, R_i]$ に含まれるすべての座標の値に $1$ を加える。  
すべての操作が終わったあと、**最も大きい値**を出力せよ。

### 制約

- $1 \le N \le 2 \times 10^5$
- $1 \le M \le 2 \times 10^5$
- $1 \le L_i \le R_i \le N$
- 入力は全て整数

### 入力

```
N M
L_1 R_1
L_2 R_2
...
L_M R_M
```

### 出力

すべての操作後の最大値を出力せよ。

---

### 入力例1

```
5 2
1 3
2 4
```

### 出力例1

```
2
```

各座標の値は `[1,2,2,1,0]`。座標 2 と 3 が `2` で最大。

---

### 入力例2

```
4 3
1 4
1 4
2 3
```

### 出力例2

```
3
```

値は `[2,3,3,2]`。

---

### 入力例3

```
3 2
1 1
3 3
```

### 出力例3

```
1
```

値は `[1,0,1]`。

---

### 練習ポイント（いもす法：区間加算を差分で）

各操作で区間を愚直に回すと $O(NM)$ で間に合わない。
**差分配列（いもす法）**: 区間 $[L,R]$ への $+1$ は、「$L$ で $+1$、$R+1$ で $-1$」と端だけ記録する。最後に**累積和**を取ると各点の値が復元できる。

```rust
let mut diff = vec![0i64; n + 2];   // R+1 が n+1 になりうるので +2 確保
for &(l, r) in &ops {
    diff[l] += 1;
    diff[r + 1] -= 1;
}
let mut cur = 0i64;
let mut mx = 0i64;
for i in 1..=n {
    cur += diff[i];      // ここで累積 = 座標 i の最終値
    mx = mx.max(cur);
}
println!("{}", mx);
```

更新が $O(M)$、復元が $O(N)$ で全体 $O(N+M)$。

認識トリガー: **「区間に一律に加算／カウントする操作がたくさん」+「最後にまとめて結果を見る」→ いもす法（差分 + 累積和）**。
配列サイズは $R+1$ まで使うので **`n+2`** で確保（境界の事故防止）。クエリ途中の値を聞かれず最後だけ見るのがいもす法を使える条件。
