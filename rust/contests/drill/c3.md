# C-3: x 以上の最小の要素

配点: 300点

### 問題文

$N$ 個の整数 $A_1, \ldots, A_N$ が与えられる。  
$Q$ 個のクエリがあり、$j$ 番目のクエリでは整数 $X_j$ が与えられる。  
各クエリについて、$A$ の中で **$X_j$ 以上の最小の要素**を出力せよ。存在しなければ `-1` を出力せよ。

### 制約

- $1 \le N, Q \le 2 \times 10^5$
- $1 \le A_i, X_j \le 10^9$
- 入力は全て整数

### 入力

```
N
A_1 A_2 ... A_N
Q
X_1
X_2
...
X_Q
```

### 出力

各クエリの答えを 1 行ずつ出力せよ。

---

### 入力例1

```
5
3 1 4 1 5
4
2
5
6
1
```

### 出力例1

```
3
5
-1
1
```

ソートすると `[1,1,3,4,5]`。
- `X=2`: 2 以上で最小は `3`
- `X=5`: `5`
- `X=6`: 6 以上は無い → `-1`
- `X=1`: `1`

---

### 入力例2

```
1
10
2
10
11
```

### 出力例2

```
10
-1
```

---

### 練習ポイント（配列への二分探索：abc463-C の型）

各クエリで線形探索すると $O(NQ)=4\times10^{10}$ で間に合わない。
**ソートしておけば、クエリは二分探索で $O(\log N)$** にできる。これが abc463-C で写経した型。今度は自力で。

Rust では `partition_point` が便利:

```rust
a.sort();
let i = a.partition_point(|&v| v < x); // 「x 未満」の個数 = x 以上の最初の位置
if i < n { println!("{}", a[i]); } else { println!("-1"); }
```

`partition_point(|&v| v < x)` は **「条件 `v < x` が true である要素の個数」**を返す（＝ C++ の `lower_bound` の位置）。
ここを `v <= x` にすると「x より大きい最初の位置」になる。境界条件で `i == n`（全部 x 未満）のときに `-1` を返すのを忘れないこと。

認識トリガー: **「ソートできる」+「同じ配列に何度も問い合わせ」→ 前処理ソート＋二分探索**。
