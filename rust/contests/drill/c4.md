# C-4: 荷物の分割で最大負荷を最小に

配点: 400点

### 問題文

ベルトコンベア上に $N$ 個の荷物が一列に並んでおり、$i$ 番目の荷物の重さは $W_i$ である。  
これを $K$ 台のトラックに積む。各トラックには**連続する区間**の荷物を積まなければならない（順番は変えられない）。  
あるトラックの負荷は、積んだ荷物の重さの合計である。

荷物をうまく分割して、**最も重いトラックの負荷（最大負荷）を最小化**したとき、その値を出力せよ。

### 制約

- $1 \le K \le N \le 2 \times 10^5$
- $1 \le W_i \le 10^9$
- 入力は全て整数

### 入力

```
N K
W_1 W_2 ... W_N
```

### 出力

最大負荷の最小値を出力せよ。

---

### 入力例1

```
5 2
1 2 3 4 5
```

### 出力例1

```
9
```

`[1,2,3]` と `[4,5]` に分けると負荷は $6$ と $9$ で、最大は $9$。これより小さくはできない。

---

### 入力例2

```
3 3
10 20 30
```

### 出力例2

```
30
```

3 台あるので 1 個ずつ。最大は $30$。

---

### 入力例3

```
5 1
1 1 1 1 1
```

### 出力例3

```
5
```

1 台に全部 → $5$。

---

### 練習ポイント（答えで二分探索：最大の最小化）

「最大値を最小化」と聞いて DP や全探索を考えると詰まる。発想を変える:

> **「最大負荷が $x$ 以下になるように $K$ 台以内で分割できるか？」** という判定問題は簡単（貪欲）。

ある容量 $x$ を仮定して、左から貪欲に詰めて溢れたら次のトラック、を繰り返し、使ったトラック数が $K$ 以下なら OK。
そして **$x$ を大きくするほど OK になりやすい（単調性）** ので、OK になる最小の $x$ を二分探索できる。

```rust
let mut lo = *w.iter().max().unwrap(); // 1個でも積めないとダメなので下限はmax
let mut hi = w.iter().sum::<i64>();    // 全部1台に積む
while lo < hi {
    let mid = (lo + hi) / 2;
    if ok(mid) { hi = mid; } else { lo = mid + 1; }
}
println!("{}", lo);
```

認識トリガー: **「最大を最小化／最小を最大化」+「ある値で可能か？の判定が簡単」→ 答えで二分探索**。
これがまさに「二分探索そこで使うんだ」という気づきの代表例。`lo` の初期値を `max` にする点（1 個も載らない容量は無意味）に注意。
