# C-5: 同じ値のペアの数

配点: 300点

### 問題文

$N$ 個の整数 $A_1, \ldots, A_N$ が与えられる。  
$1 \le i < j \le N$ かつ $A_i = A_j$ を満たす組 $(i, j)$ の個数を求めよ。

### 制約

- $1 \le N \le 2 \times 10^5$
- $1 \le A_i \le 10^9$
- 入力は全て整数

### 入力

```
N
A_1 A_2 ... A_N
```

### 出力

条件を満たす組の個数を出力せよ。

---

### 入力例1

```
4
1 1 1 2
```

### 出力例1

```
3
```

`1` が 3 個あるので組は $\binom{3}{2}=3$ 通り。`2` は 1 個なので組は無い。

---

### 入力例2

```
4
5 5 5 5
```

### 出力例2

```
6
```

$\binom{4}{2}=6$。

---

### 入力例3

```
3
1 2 3
```

### 出力例3

```
0
```

---

### 練習ポイント（HashMap でカウント）

「同じ値のペア」を二重ループで数えると $O(N^2)$ で TLE。
**各値が何個あるか**を数えれば、値ごとに $\binom{c}{2} = \dfrac{c(c-1)}{2}$ を足すだけ。

```rust
use std::collections::HashMap;
let mut cnt: HashMap<i64, i64> = HashMap::new();
for &x in &a { *cnt.entry(x).or_insert(0) += 1; }
let ans: i64 = cnt.values().map(|&c| c * (c - 1) / 2).sum();
```

`entry(x).or_insert(0)` は「キー x が無ければ 0 を入れて、その可変参照を返す」イディオム。`*...+= 1` でカウント。

認識トリガー: **「出現回数を数える」「同じ値の組」→ HashMap でカウント**。
$A_i \le 10^9$ なので添字配列では持てない（→ HashMap）。答えは最大 $\binom{2\times10^5}{2}\approx 2\times10^{10}$ なので **`i64`**。
