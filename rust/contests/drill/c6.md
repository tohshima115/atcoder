# C-6: 和が K になる 2 つ

配点: 300点

### 問題文

$N$ 個の整数 $A_1, \ldots, A_N$ と整数 $K$ が与えられる。  
相異なる 2 つの要素（添字が異なる $i \ne j$）で、$A_i + A_j = K$ となる組が存在するか判定せよ。  
存在すれば `Yes`、しなければ `No` を出力せよ。

### 制約

- $2 \le N \le 2 \times 10^5$
- $1 \le A_i \le 10^9$
- $1 \le K \le 2 \times 10^9$
- 入力は全て整数

### 入力

```
N K
A_1 A_2 ... A_N
```

### 出力

`Yes` または `No` を出力せよ。

---

### 入力例1

```
3 5
1 2 3
```

### 出力例1

```
Yes
```

$2 + 3 = 5$。

---

### 入力例2

```
3 10
1 2 3
```

### 出力例2

```
No
```

どの 2 つを足しても 10 にならない。

---

### 入力例3

```
2 8
4 4
```

### 出力例3

```
Yes
```

添字の異なる 2 つの `4` で $4 + 4 = 8$。

---

### 練習ポイント（HashSet で相方探し）

全ペアを試すと $O(N^2)$。代わりに、各要素 $A_i$ について **相方 $K - A_i$ がすでに出たか** を集合で確認しながら進めれば $O(N)$。

```rust
use std::collections::HashSet;
let mut seen: HashSet<i64> = HashSet::new();
let mut ans = false;
for &x in &a {
    if seen.contains(&(k - x)) { ans = true; break; }
    seen.insert(x);
}
println!("{}", if ans { "Yes" } else { "No" });
```

ポイントは **「今の要素を入れる前に相方を探す」** こと。先に insert すると、同じ要素を 2 回使ってしまう危険がある（入力例3 のように本当に 2 個あるならセーフだが、1 個しかない値で `K = 2*x` のとき誤判定する）。

認識トリガー: **「和が K になるペアの存在」→ 相方 `K - x` を集合で探す**（two-sum の型）。
$K$ は最大 $2\times10^9$ なので **`i64`**（`k - x` が i32 を超えうる）。
