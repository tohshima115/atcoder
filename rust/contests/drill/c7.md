# C-7: 区間和クエリ

配点: 300点

### 問題文

$N$ 個の整数 $A_1, \ldots, A_N$ が与えられる。  
$Q$ 個のクエリがあり、$j$ 番目のクエリでは整数 $L_j, R_j$ が与えられる。  
各クエリについて、$A_{L_j} + A_{L_j+1} + \cdots + A_{R_j}$（区間 $[L_j, R_j]$ の和）を出力せよ。

### 制約

- $1 \le N, Q \le 2 \times 10^5$
- $1 \le A_i \le 10^9$
- $1 \le L_j \le R_j \le N$
- 入力は全て整数

### 入力

```
N
A_1 A_2 ... A_N
Q
L_1 R_1
L_2 R_2
...
L_Q R_Q
```

### 出力

各クエリの答えを 1 行ずつ出力せよ。

---

### 入力例1

```
5
1 2 3 4 5
3
1 3
2 5
4 4
```

### 出力例1

```
6
14
4
```

- $[1,3]$: $1+2+3=6$
- $[2,5]$: $2+3+4+5=14$
- $[4,4]$: $4$

---

### 入力例2

```
3
10 20 30
1
1 3
```

### 出力例2

```
60
```

---

### 練習ポイント（累積和：クエリ高速化の基本）

クエリごとに足すと $O(NQ)$ で間に合わない。**累積和 $S_i = A_1 + \cdots + A_i$**（$S_0 = 0$）を前計算しておけば、区間和は $S_R - S_{L-1}$ で $O(1)$。

```rust
let mut pre = vec![0i64; n + 1];
for i in 0..n { pre[i + 1] = pre[i] + a[i]; }
// クエリ (l, r) は 1-indexed
let ans = pre[r] - pre[l - 1];
```

**1-indexed と 0-indexed のズレ**が事故りやすいポイント。`pre` を長さ $N+1$ で `pre[0]=0` から作ると、区間 $[L,R]$ の和は素直に `pre[R] - pre[L-1]` になる。

認識トリガー: **「区間の和を何度も聞かれる」→ 累積和を前計算**。
和は $10^{14}$ 級なので **`i64`**。
