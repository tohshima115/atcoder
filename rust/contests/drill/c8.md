# C-8: 和が K の倍数になる区間の数

配点: 400点

### 問題文

$N$ 個の整数 $A_1, \ldots, A_N$ と整数 $K$ が与えられる。  
連続する部分列（区間）$[l, r]$ のうち、その和 $A_l + \cdots + A_r$ が **$K$ の倍数**になるものの個数を求めよ。

### 制約

- $1 \le N \le 2 \times 10^5$
- $1 \le K \le 10^9$
- $1 \le A_i \le 10^9$
- 入力は全て整数

### 入力

```
N K
A_1 A_2 ... A_N
```

### 出力

和が $K$ の倍数になる区間の個数を出力せよ。

---

### 入力例1

```
3 3
2 1 3
```

### 出力例1

```
3
```

- $[1,2]$: $2+1=3$（3 の倍数）
- $[1,3]$: $2+1+3=6$
- $[3,3]$: $3$

---

### 入力例2

```
5 5
1 2 3 4 5
```

### 出力例2

```
4
```

$[2,3]=5$, $[1,4]=10$, $[5,5]=5$, $[1,5]=15$ の 4 個。

---

### 入力例3

```
3 5
5 5 5
```

### 出力例3

```
6
```

どの区間の和も 5 の倍数。区間は $\binom{3+1}{2}=6$ 通り…ではなく、$[l,r]$ の個数 $\binom{4}{2}=6$。

---

### 練習ポイント（累積和 + 余り + カウント）

区間和 $[l,r]$ は $S_r - S_{l-1}$。これが $K$ の倍数 $\iff S_r \equiv S_{l-1} \pmod K$。
つまり **「累積和を $K$ で割った余りが等しい 2 つの添字 $(l-1, r)$ の組」を数える**問題に変わる。

各余りが何回出たかを数えながら進める。`S_0 = 0` を最初に 1 回数えておくのを忘れない（区間が先頭から始まるケース）。

```rust
use std::collections::HashMap;
let mut cnt: HashMap<i64, i64> = HashMap::new();
cnt.insert(0, 1);           // S_0 = 0 を登録
let mut pre = 0i64;
let mut ans = 0i64;
for &x in &a {
    pre = (pre + x) % k;
    let c = cnt.entry(pre).or_insert(0);
    ans += *c;              // すでに同じ余りが出た回数だけ区間が作れる
    *c += 1;
}
println!("{}", ans);
```

認識トリガー: **「和が K の倍数／和がちょうど〜の区間の数」→ 累積和を取って『同じ値（余り）の組を数える』に言い換える**。
これは C〜D で頻出の強力な型。`S_0=0` の初期登録と、答えが $10^{10}$ 級になる（→ **`i64`**）点に注意。
