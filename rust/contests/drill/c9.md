# C-9: 和が K 以下の最長区間

配点: 300点

### 問題文

$N$ 個の**正の**整数 $A_1, \ldots, A_N$ と整数 $K$ が与えられる。  
連続する部分列のうち、和が $K$ 以下であるものの中で、**最も長いものの長さ**を求めよ。

### 制約

- $1 \le N \le 2 \times 10^5$
- $1 \le A_i \le 10^9$
- $1 \le K \le 10^{18}$
- 入力は全て整数

### 入力

```
N K
A_1 A_2 ... A_N
```

### 出力

和が $K$ 以下の最長区間の長さを出力せよ（条件を満たす区間が無ければ `0`）。

---

### 入力例1

```
4 4
1 2 3 1
```

### 出力例1

```
2
```

`[1,2]`（和 3）や `[3,1]`（和 4）が長さ 2。`[1,2,3]` は和 6 で超える。

---

### 入力例2

```
4 10
1 1 1 1
```

### 出力例2

```
4
```

全体の和 4 ≤ 10。

---

### 入力例3

```
3 3
5 1 2
```

### 出力例3

```
2
```

`[1,2]`（和 3）が長さ 2。先頭の `5` は単独でも 3 を超える。

---

### 練習ポイント（尺取り法）

全区間 $O(N^2)$ は $4\times10^{10}$ で間に合わない。
**要素が全部正**だと、右端 $r$ を進めると和は増え、左端 $l$ を進めると和は減る、という**単調性**がある。これが尺取り法の前提。

右端 $r$ を 1 つずつ伸ばし、和が $K$ を超えたら左端 $l$ を必要なだけ進めて $K$ 以下に戻す。各区間で長さの最大を更新:

```rust
let mut l = 0usize;
let mut sum = 0i64;
let mut best = 0usize;
for r in 0..n {
    sum += a[r];
    while sum > k { sum -= a[l]; l += 1; }
    best = best.max(r - l + 1);
}
println!("{}", best);
```

$l$ と $r$ はそれぞれ最大 $N$ 回しか進まないので全体で $O(N)$。

認識トリガー: **「連続部分列」+「和や種類数が条件以下になる最長／個数」+「単調性がある（全部正など）」→ 尺取り法**。
和は $10^{14}$ 級だが $K$ が最大 $10^{18}$ なので比較も含め **`i64`**。`l` が `r` を追い越さない（空区間の扱い）点に注意。
