## 問題へのリンク

[ABC467 C - Adjacent Sums (easy)](https://atcoder.jp/contests/abc467/tasks/abc467_c)

## 問題の要約

$0$ 以上 $M-1$ 以下の整数列 $A=(A_1,\dots,A_N)$, $B=(B_1,\dots,B_{N-1})$。操作は「$A_i$ に $1$ を加える」を好きな回数。すべての $i$ で $(A_i+A_{i+1}) \bmod M = B_i$ にするための**最小操作回数**を求める。C問題は **$M=2$**（Eは一般の $M$、[[abc467e]] 参照）。

## 方針（$M=2$）

$M=2$ なのでパリティ（偶奇）だけが問題。各 $A_i$ を最終的にどのパリティ $a_i \in \{0,1\}$ にするか決める話に帰着する。

- パリティを変えるコストは、$+1$ を1回すれば反転できるので **元と違えば 1、同じなら 0**。
- 条件 $(a_i + a_{i+1}) \bmod 2 = B_i$。

### 解法1: パリティ連鎖（おすすめ・シンプル）

条件を変形すると

$$a_{i+1} = (B_i + a_i) \bmod 2$$

つまり **$a_1$ を決めれば $a_2,\dots,a_N$ が芋づる式に全部確定**する。自由度は $a_1 = 0$ か $1$ の **2通りだけ**。両方について「$a_i \ne A_i$ の個数（＝コスト）」を数えて小さい方が答え。$O(N)$。

```rust
fn cost(start: i64, a: &[i64], b: &[i64], n: usize) -> i64 {
    let mut cur = start;
    let mut c = if cur != a[0] { 1 } else { 0 };
    for i in 0..n - 1 {
        cur = (b[i] + cur) % 2;          // 次のパリティを確定
        if cur != a[i + 1] { c += 1; }   // A_{i+1} と比較する点に注意
    }
    c
}
// let ans = cost(0, &seta, &setb, n).min(cost(1, &seta, &setb, n));
```

### 解法2: ミスマッチのペアリング（コンテストで書きかけた方針）

$A_j$ に $1$ 足すと、条件 $i=j-1$ と $i=j$ の **2つが同時にトグル**する。連続区間 $[l,r]$ の要素を反転すると途中が打ち消し合い、**両端の条件 $l-1$ と $r$ だけ**がトグルする（コスト $= r-l+1$）。

→ 「今ズレている条件」を $2$ つペアにして直すコストは **$q-p$（位置の距離）**。だから:

1. ズレ位置 $p$ を列挙。**ズレの定義は $((A_i+A_{i+1}) - B_i) \bmod 2 = 1$**（＝ `(A_i+A_{i+1}+B_i) % 2`。$B$ を必ず使う！）。
2. 昇順に並べ、隣り合う $2$ 個ずつペアにして距離を合計。
3. 端に逃がす場合は**仮想端点**を追加してからペアリング:
   - 左端 = **$-1$**（位置 $p$ を左に繋ぐコスト $= p-(-1)=p+1$）
   - 右端 = **$N-1$**（コスト $= (N-1)-p$）

| ズレ個数 | 候補a | 候補b |
|---|---|---|
| 偶数 | `p` そのまま | `[-1] + p + [N-1]`（両端使用） |
| 奇数 | `[-1] + p`（左端1つ） | `p + [N-1]`（右端1つ） |

両方計算して min。ペア和は「2個ずつ取って `右 - 左` を足す」。

**解法1と解法2は同じ問題の別表現**：`a_i != A_i`（反転するか）が解法2の「要素の反転」に対応し、`a_1` の2択が「左端を使うか否か」に対応する。

## このセッションで学んだこと

### パリティ連鎖：先頭を決めると全部確定（頻出パターン）

$(a_i + a_{i+1}) \equiv B_i$ のような**隣接2項の関係**は、$a_{i+1} = f(a_i)$ の漸化式に直せる。すると**先頭 $a_1$ の値だけが自由変数**になり、$M$ 通り（$M=2$ なら2通り）試すだけで最適が出る。パリティ・XOR・mod 系で超頻出。

知識レベル: 🟢 実装可能（漸化式に落として先頭2択、は書ける）

### 今回詰まった原因（反省）

1. **$B$（`setb`）を条件判定に入れ忘れた**。「今の隣接和のパリティ」ではなく「$B$ と一致しているか」で判定しないと無意味。式は `(A_i + A_{i+1} + B_i) % 2`。
2. **仮想端点の値**を $0$ ではなく **$-1$ / $N-1$** にする必要があった（距離 = コスト にするため）。
3. `Vec<usize>` に $-1$ を入れられない型の壁 → 位置は `i64` で持つ。

知識レベル: 🟡 雰囲気理解（方針は正しかった。実装ディテールを詰め切れず時間切れ）
